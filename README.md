This project is an interactive data visualization dashboard designed to explore, analyze, and present insights from young adult mental health data. The dashboard allows users to identify trends, patterns, and key metrics that support data-driven decision-making and improve access of mental health services for college students.

Objectives : 
  Build an interactive dashboard for healthcare data exploration
  Visualize key trends and performance metrics
  Improve understanding of patient or operational data
  Support data-driven decision-making

Technologies Used : 
  Tableau Desktop and Prep
  Microsoft Power BI
  Microsoft PowerPoint 
  Excel

Features :
  Interactive charts and filters
  Dynamic data exploration
  KPI tracking and visualization
  Clean and user-friendly dashboard layout
